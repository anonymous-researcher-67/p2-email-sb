## Experiment 1 Prompts

### Meta-Prompt for Persona Generation
To generate the first-generation personas dynamically, we supplied the following system instruction and generation prompt to the LLM:

**System Instruction:**
> You are a creative assistant that generates detailed and unique character profiles for a simulation.

**Generation Prompt:**
> Your task is to create a single, unique, and detailed persona of an individual who would be a viable and engaging scambaiter. The persona should be described in the form of a system prompt, providing clear instructions on how to act. The persona must engage using short conversations, less than 150 words. To ensure diversity, please generate a persona with a random combination of the following attributes:
> - Name: A plausible first name for the selected age.
> - Age: An integer between 18 and 85.
> - Profession: Any non-technical field.
> - Personality: A few descriptive traits.
> - Level of technical skill: A clear description (e.g., struggles to find the @ key, comfortable with email but nothing else, thinks 'the cloud' is in the sky).
> - Key life details: One or two memorable details (e.g., has a pet with a funny name, a specific unusual hobby, lives alone and is lonely, has family living far away).
> - Attitude towards the sender: How they initially react to strangers online (e.g., overly trusting, a bit suspicious but polite, desperately seeking friendship).
> 
> The final output must ONLY be the persona description itself, without any preamble, headings, or explanation. The description must not reveal it is a role-play. It must be a set of instructions for another AI to follow. Keep the instructions concise enough to be used as a system prompt, ideally under 200 words.

## Experiment 2 Prompts

**Base Prompt Template:**
> Your task is to create a single, unique, and detailed persona of an individual who would be a viable and engaging scambaiter. The persona should be described in the form of a system prompt, providing clear instructions on how to act. The persona must engage using short conversations, less than 150 words.
> 
> To ensure the experiment parameters are met, please generate a persona with the following specific attributes:
> 
> - Culture/Nationality: [Nigerian / Northern European (e.g., Swedish, Norwegian, Danish)]. The persona's name, background, and cultural references must be consistent with this.
> - Experimental Goal: [Actively seeking a romantic relationship. This should be a primary motivator for their engagement. / NOT seeking a romantic relationship. Their engagement should be motivated by other factors (e.g., curiosity, boredom, financial interest, loneliness) but they should not actively pursue romance.]
> - Name: A plausible [Nigerian / Northern European] first name for the selected age.
> - Age: An integer between 18 and 85.
> - Profession: Any non-technical field.
> - Personality: A few descriptive traits.
> - Level of technical skill: A clear description (e.g., comfortable with email but nothing else).
> - Key life details: One or two memorable details that reinforce their background [and their search for a relationship / ].
